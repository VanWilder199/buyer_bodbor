# Бэкенд: что доработать (сводный список)

> Все бэкенд-доработки из фронтовых планов и финального чек-листа в одном месте, без дублей и в порядке работы.
> Подробные контракты (JSON, коды ошибок) остаются в исходных документах. Здесь — что сделать, зачем и где читать детали.
> Пишется в режиме «объяснение → код»: готового кода здесь нет.
>
> Сверено с кодом 2026-09-29 (коммит `153ef5c` + рабочая копия), дополнено по `REVIEW_REPORT.md` 2026-10-01.

**Источники** (колонка «Где подробно»):
- `G-n` — `PLAN_FRONTEND.md`, «Пробелы бэкенда» (покупатель);
- `ADM BE-n` — `PLAN_FRONTEND_ADMIN.md`, раздел 4;
- `MINI BE-n` — `PLAN_FRONTEND_MINIAPP.md`, раздел 5;
